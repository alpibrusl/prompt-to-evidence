# Colophon

This book is written in Markdown and built with
[content-kit](https://github.com/alpibrusl/content-kit), an open-source
toolchain for books-as-code. The manuscript lives in a repository with its
full history — [alpibrusl/prompt-to-evidence](https://github.com/alpibrusl/prompt-to-evidence)
— where a term-continuity linter checks that no word is used before it is
defined, and the same source renders to EPUB, HTML and PDF.

It is one of three companions to [*Prompt to
Production*](https://github.com/alpibrusl/prompt-to-production), same
tooling and the same discipline, applied to analytical correctness instead
of software engineering. [*Prompt to
Ledger*](https://github.com/alpibrusl/prompt-to-ledger) applies it to
financial correctness, and [*Prompt to
Decision*](https://github.com/alpibrusl/prompt-to-decision) applies it to
the layer above all three — deciding whether to act on a recommendation.
